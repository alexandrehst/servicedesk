ServiceDesk
Hexagonal, MCP-first.

A espinha de invariantes que os épicos herdam. Um núcleo de domínio no centro; MCP e API HTTP são apenas tradutores que batem no mesmo núcleo. "MCP e UI consomem a mesma camada de domínio" deixa de ser boa intenção e vira regra estrutural.

O hexágono

Dependências apontam só para dentro (AD-1). Fora, os adapters; dentro, o domínio puro.

Driving adapters (entrada) Núcleo de domínio Driven adapters (saída) Adiado (Fase 1.5)

Um exemplo: fechar_chamado via IA

A mesma regra vale para MCP e API — porque ela mora no domínio, não no adapter.

1IA chama a tool fechar_chamado(#1042) no adapter MCP.
2Adapter valida o input pelo schema Zod único (AD-6) e monta o principal {identidade, papel, origin: mcp} (AD-9).
!Guardrail (AD-7): é Ação irreversível → o domínio exige confirmação humana explícita. Sem ela, nada muda e a tool devolve pedido de confirmação.
3Com confirmação, o command handler (application) checa autorização (AD-8), a transição de Status (AD-5) e a versão esperada (AD-10).
4Numa única transação: grava a mudança + o registro de auditoria com autor e origin (AD-3).
5Port de notificação dispara o e-mail de resolução (AD-1). A UI web, quando existir, passaria pelos mesmos passos 2–5.

Os 10 invariantes (ADs)

O que dois módulos um nível abaixo não podem escolher de formas incompatíveis.

AD-1
Dependências só para dentro
Impede: lógica vazar para os adapters e MCP/API divergirem.
AD-2
Domínio é o único ponto de mutação
Impede: dois caminhos de escrita paralelos.
AD-3
Auditoria transacional (autor+origem)
Impede: lacunas e inconsistência de auditoria.
AD-4
Número vem de sequence do banco
Impede: IDs conflitantes; Número mutável.
AD-5
Status: máquina fechada no domínio
Impede: MCP permitir transição que a API proíbe.
AD-6
Contratos de uma fonte Zod única
Impede: schema das tools divergir da API.
AD-7
Irreversíveis exigem confirmação
Impede: o MCP pular o human-in-the-loop.
AD-8
Autorização no domínio (papel+posse)
Impede: MCP expor o que a UI esconde.
AD-9
Identidade+origem até a auditoria
Impede: autoria ambígua (humano-via-IA vs. autônomo).
AD-10
Concorrência otimista no handler
Impede: MCP e API tratarem edição concorrente diferente.

O que fica adiado

A metade do contrato que mantém a spine enxuta.

Topologia de deploy
Provider e forma (container vs. serverless) — escala pequena permite adiar.
Transporte MCP em produção
Começar stdio local; promover a HTTP autenticado quando >1 cliente precisar.
Auth concreta
Magic link vs. login corporativo — o port fixa, a implementação fica aberta.
Migração CSV
Formato de export do contratado desconhecido — adapter desenhado quando conhecido.
